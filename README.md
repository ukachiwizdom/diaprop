# DIAPROP — Digital Property Access Platform 🏠🇳🇬

Nigeria's verified real estate marketplace with virtual inspections, live scheduling, and direct agent messaging.

## Features
- 🔍 Browse & filter property listings (Sale / Rent / Lease)
- 📅 Schedule virtual or physical inspections
- 💬 Real-time chat with agents through listings
- ✓ Verified agents & properties
- 📱 Fully responsive (mobile + desktop)
