# DIAPROP — Digital Property Access Platform 🏠🇳🇬

Nigeria's verified real estate marketplace with virtual inspections, live scheduling, and direct agent messaging.

## Features
- 🔍 Browse & filter property listings (Sale / Rent / Lease)
- 📅 Schedule virtual or physical inspections
- 💬 Real-time chat with agents through listings
- ✓ Verified agents & properties
- 📱 Fully responsive (mobile + desktop)

## Deploy to Vercel (3 minutes)

```bash
# 1. Push to GitHub
git init && git add . && git commit -m "DIAPROP MVP"
# Create repo at github.com/new, then:
git remote add origin https://github.com/YOUR_USERNAME/diaprop.git
git push -u origin main

# 2. Go to vercel.com → Import repo → Deploy
# Your app: https://diaprop.vercel.app
```

## Run Locally

```bash
npm install
npm start
# Opens at http://localhost:3000
```

## Tech Stack
- React 18 (zero extra dependencies)
- Pure CSS-in-JS styling
- Syne + DM Sans fonts
